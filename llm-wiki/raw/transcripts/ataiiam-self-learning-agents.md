# Self-Learning Agents: 4 уровня самообучения

**Источник:** [Twitter/X Status @ataiiam](https://x.com/ataiiam/status/2069797329809395978)

Агент должен становиться лучше с течением времени. Для этого существует 4 направления (слоя) обучения:

## 1. Model Layer (Уровень модели)
- **Суть:** Сама модель улучшает свои веса или генерирует данные для дообучения.
- **Механика:** Модель редактирует свой код, прогоняет через скорер, и оставляет то, что работает (code & math).
- **Применимость:** Хорошо работает только в доменах с объективной функцией оценки (математика, код). Менее применимо для поддержки или продаж.
- **Примеры:** Self-Adapting LLMs, AlphaEvolve. Обычно это прерогатива крупных AI-лабораторий.

## 2. Harness Layer (Уровень обвязки)
- **Суть:** Заморозка весов модели и улучшение окружающей её программной инфраструктуры (Harness).
- **Механика:** Переписывание пайплайнов, промптов и инструментов агента на основе его собственных логов (traces). Агент сам оптимизирует свою "обвязку", и за счет этого метрики растут.
- **Практика:** Loop Engineering. Это самый быстрый путь получить видимые результаты.

## 3. Context Layer (Уровень контекста/памяти)
- **Суть:** Внешняя память и навыки, которые переживают конкретную сессию модели.
- **Механика:** "Write what worked, read it next run".
  - Переписывание и обновление файлов памяти в фоновом режиме.
  - Анализ ошибок и исправление инструкций в файле `SKILL.md`.
  - Сохранение успешного выполнения задачи в виде нового переиспользуемого навыка.
- **Примеры:** OpenClaw, Anthropic Skills.

## 4. The Missing Signal (Обучение от пользователей)
- **Проблема:** Все предыдущие слои наблюдают за агентом. Но никто не наблюдает за конечным пользователем.
- **Суть:** Агент должен извлекать опыт каждый раз, когда человек исправляет решение агента.
- **Механика:** Анализ расхождений между тем, что сделал агент, и тем, что в итоге закомитил/исправил пользователь. Ничто не заменит этот реальный production-сигнал.
- **Примеры:** CopilotKit, AG-UI (интерфейсы, которые видят и агента, и действия пользователя).
