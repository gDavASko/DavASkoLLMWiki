# Эволюция работы с AI-агентами: Harness Engineering

**Источник:** [Видео uY-k4-iHDJw](https://www.youtube.com/watch?v=uY-k4-iHDJw)

## Эволюция подходов
Развитие взаимодействия с LLM прошло несколько этапов:

### Prompt Engineering (2023-2024)
- **Фокус:** Написание идеальных промптов для получения приемлемого результата.
- **Ограничения:** Маленькое контекстное окно (4096 токенов).

### Context Engineering (2024)
- **Фокус:** Насыщение огромных контекстных окон (от 256k до 1M токенов) релевантной информацией.
- **Инструменты:** RAG, Tool Calling, MCP (Model Context Protocol).
- **Проблемы:** 
  - Необходимость компактизации (compaction) контекста.
  - **Context Rot:** Деградация качества ответов агента при переполнении контекстного окна историей сообщений.

### Harness Engineering (2026+)
- **Концепция:** Управление всем процессом выполнения задач через внешнюю "обвязку" (Harness). Агент становится лишь вычислительным ядром внутри жесткой структуры.
- **Компоненты:** Инструменты Context Engineering + Оркестрация + Skills + Environment.

## Environment (Окружение)
Среда, в которой работает агент, включает:
1. Грамотный исходный контекст.
2. PRD (Product Requirements Document) и документацию.
3. Планы и спецификации.
4. Правила выполнения (Guardrails).
5. Тестирование и Feedback loops.
6. Внешние инструменты (Skills).

## Ralph Loop: Атомарность и изоляция
Ralph Loop является ядром Harness Engineering.
- **Принцип работы:** PRD разбивается на спецификации -> формируются атомарные задачи (Atomic Tasks) -> выполняются через Agentic Loop.
- **Ключевые отличия:**
  - **Очистка контекста:** Каждая новая задача или итерация стартует с абсолютно чистым контекстным окном.
  - **Zero Compaction:** Отказ от механизмов сжатия истории сессии.
  - Состояние передается через внешнюю файловую память, а не тянется за моделью в виде длинного диалога.

## Итог
Harness Engineering позволяет достичь настоящей автономности агентов за счет жесткого контроля их окружения и правил. Модель не предоставлена сама себе, а действует в рамках строго детерминированного процесса, что обеспечивает предсказуемые и качественные результаты без архитектурной деградации.
